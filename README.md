# multitracker-search

Поддерживаемый форк [TMS — Torrents MultiSearch](https://github.com/Feverqwe/tSearch) (Feverqwe/tSearch, архивирован в 2022): браузерное расширение, которое ищет раздачи сразу на нескольких торрент-трекерах и собирает результаты в одну таблицу с фильтрами.

## Трекеры

| Трекер | Вход на сайт | Примечание |
|---|---|---|
| Рутрекер | нужен | Cloudflare |
| NNM-Club | — | |
| Кинозал | — | зеркало kinozal.me, Cloudflare |
| Рутор | — | |
| MegaPeer | — | |
| The Pirate Bay | — | через JSON API apibay.org |
| LimeTorrents | — | |
| rgFootball | — | |
| Книжный трекер | нужен | |
| Tapochek | нужен | |
| Piratbit | нужен | Cloudflare, не проверен |
| Rustorka | нужен | Cloudflare |

Запросы расширения используют куки браузера, включая «разделённую» куку Cloudflare `cf_clearance`: браузер сам её в запросы расширения не кладёт, поэтому расширение подставляет её через `chrome.cookies` + `webRequest` (`src/tools/partitionedCookies.js`). Если у трекера в списке значок «Войти», откройте сайт по этой ссылке, войдите или пройдите проверку Cloudflare и повторите поиск. Так же работают подборки IMDb на главной: IMDb иногда требует один раз открыть сайт.

## Что изменено относительно 3.1.2

## Сборка

Нужен Node 18 (`.nvmrc`). Сборщик — webpack 4.

```bash
nvm use
npm ci
npm run release
```

Результат: распакованное расширение в `dist/dist/` и архив `dist/tms-<версия>.zip`.

- `npm run build` — сборка для разработки (с source map), `npm run watch` — пересборка при изменениях.
- `src/trackers.json` и `src/explorers.json` (версии встроенных трекеров и подборок) генерирует `npm run release`. При изменении трекера поднимите `@version` в его файле, иначе у установленного расширения останется закэшированная старая версия.

## Установка

Расширение на Manifest V2: его загружают Vivaldi и браузеры, где MV2 ещё поддерживается. Chrome MV2-расширения больше не запускает.

1. Откройте `vivaldi://extensions` и включите режим разработчика.
2. «Загрузить распакованное» → папка `dist/dist`.
3. После пересборки нажмите «Обновить» у расширения.

В `manifest.json` прописан `key` оригинального расширения, поэтому ID расширения совпадает с прежней установкой: профили, история и настройки сохраняются.

## Как устроены трекеры

Трекер — файл `src/trackers/<id>.js` с заголовком userscript (`@name`, `@version`, `@connect` и т.д.). Сборка копирует его как есть. Большинство трекеров описаны декларативно через exKit (`"type": "kit"`, `"version": 3`): URL поиска плюс селекторы строк и полей с конвейером обработки (`getText`, `getProp`, `toInt`, `legacySizeFormat`...). Если нужна своя логика, трекер может сам вызвать `API_request` и `API_event('search', ...)` — так сделан `thepiratebay.js`.

Хорошая подсказка для актуальных селекторов — определения [Jackett](https://github.com/Jackett/Jackett/tree/master/src/Jackett.Common/Definitions).
